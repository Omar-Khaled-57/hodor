# Hodor visual identity

Hodor's "Gatekeeper" interface uses a cool, high-contrast navy foundation with
neon teal for active states. The light mode uses clean blue-white surfaces and
the same green family at a darker, readable value.

| Role | Color |
| --- | --- |
| Dark background / surface | ![#060B14](https://img.shields.io/badge/-%23060B14?style=flat-square&color=060B14) `#060B14` / `#0D1824` |
| Dark accent | ![#00E8A2](https://img.shields.io/badge/-%2300E8A2?style=flat-square&color=00E8A2) `#00E8A2` |
| Light background / surface | ![#F0F6FF](https://img.shields.io/badge/-%23F0F6FF?style=flat-square&color=F0F6FF) `#F0F6FF` / `#FFFFFF` |
| Light accent | ![#00C47A](https://img.shields.io/badge/-%2300C47A?style=flat-square&color=00C47A) `#00C47A` |
| Safety/status colors | danger `#E11D48`; warning `#D97706` |

The theme is defined in [`src/app/globals.css`](../src/app/globals.css), with
dark-mode selection represented by `html.dark`. The README describes the
attendance and RFID workflows: [`README.md`](../README.md).
